# Kasus 1 · Surveilans Kesehatan Kerja PT Serat Nusa Tekstil (Kelompok 3)

Website jawaban praktikum MK Kesehatan Kerja, Pertemuan 9: dashboard surveilans bulanan November 2026, jawaban Soal 1–6, rekomendasi hierarki pengendalian, dan daftar pustaka 2020–2026.

- `index.html` — website satu halaman (tanpa build, tanpa framework).
- `assets/Kasus1_Surveilans_PT_Serat_Nusa_Tekstil_Kelompok3.xlsx` — workbook Excel dengan seluruh perhitungan berbasis rumus.

## Menampilkan sebagai website (GitHub Pages)

1. Buka **Settings → Pages** pada repo ini.
2. Pada **Build and deployment → Source**, pilih **Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
4. Tunggu 1–2 menit; alamat website muncul di bagian atas halaman Pages, biasanya `https://<username>.github.io/<nama-repo>/`.

Semua data dalam kasus ini fiktif untuk latihan.
